MathML (extra credit)

Einstein's mass–energy equivalence:

E = m c 2

MathML has been part of the HTML standard for years, but developers couldn't rely on it because browser support was uneven. Firefox supported it early, while Chrome briefly shipped it and then removed it, and only added MathML Core support in Chrome 109 in January 2023. Until all major browsers supported it, sites used workarounds like images of equations or JavaScript libraries such as MathJax.

Validation notes

Every page of this site validates with no errors when I upload the HTML files directly to validator.w3.org (Validate by File Upload).

When I validate the live Netlify URLs, every page reports one error, “Stray start tag script,” followed by a fatal error. The reported line is a <script> tag pointing to /.netlify/scripts/hud that appears after my closing </html> tag. That script is not in my source files. Netlify adds it to the page when serving it, for its “Heads-up Display” collaboration toolbar. HTML doesn't allow any elements after </html>, so the validator rejects it and stops checking the rest of the page.

What I tried

  1. Validated my local files by file upload to confirm my own markup has no errors.
  2. Viewed the live page source and confirmed the extra script appears only after </html>, outside my code.
  3. Looked for the setting to turn the Heads-up Display off (Project configuration → Developer settings → Collaboration tools). That section isn't available because my project is deployed by drag-and-drop instead of a linked Git repository.
  4. Checked Snippet injection under Developer settings and found no snippets I could remove.

My theory

Netlify injects this toolbar script on manual deploys by default and doesn't offer a way to disable it unless a repository is linked. The error comes from the hosting platform, not from my HTML.
